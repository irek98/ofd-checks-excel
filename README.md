## Ключевые теги ФФД

| Тег | Поле |
|---|---|
| 1059 | наименование предмета расчёта |
| 1023 | количество |
| 1079 | цена |
| 1043 | стоимость позиции |
| 1199 | ставка НДС |
| 1040 / 1041 / 1077 | номер ФД / номер ФН / ФПД |

Ключ уникальности чека — **ФН + ФД + ФПД**. Удалять дубли нужно по нему, а не по сумме и дате:
у двух чеков в одну минуту на одинаковую сумму разные ФД.

## Три ошибки, которые ломают отчёт

1. **В файле только шапки чеков, без позиций.** В отчёте по документам есть дата, сумма, ФД и ФПД,
   но нет наименований — нужен отчёт с составом чека или выгрузка через API.
2. **Период обрезан лимитом кабинета.** Кабинет ОФД обычно отдаёт не больше месяца-квартала за раз;
   длинный период делится на интервалы и склеивается.
3. **Возвраты посчитаны вместе с приходами.** Признак расчёта (тег 1054) нужно учитывать отдельно,
   иначе выручка завышена.

## Как проверить готовый файл

- сумма строк внутри чека равна итогу чека;
- число чеков совпадает со счётчиком документов в кабинете за тот же период;
- нет дублей по связке ФН + ФД + ФПД;
- кодировка UTF-8 и разделитель, который понимает Excel (в русской локали — `;`);
- длинные ФН (12 цифр) и ФПД (10 цифр) не превратились в экспоненту.
